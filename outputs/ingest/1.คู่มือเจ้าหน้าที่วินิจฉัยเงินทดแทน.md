ระบบแจ้งการประสบอันตรายเนื่องจากการทำงาน (e-Compensate) สำหรับเจ้าหน้าที่วินิจฉัยเงินทดแทน 
****************************** 

สำนักงานประกันสังคมได้พัฒนาระบบแจ้งการประสบอันตรายเนื่องจากการทำงาน (e-Compensate) โดยระบบเชื่อมโยงข้อมูลกับสำนักงานประกันสังคมกรุงเทพมหานครพื้นที่/จังหวัด/สาขา และสถานพยาบาลในความตกลงของกองทุนเงินทดแทน เพื่อให้นายจ้าง ลูกจ้างสามารถแจ้งการประสบอันตรายเนื่องจากการทำงานและขอรับเงินทดแทนผ่าน Mobile Application (IOS และ Android) ผ่าน Web Application (Internet และ Intranet) โดยมีขั้นตอน ดังนี้
